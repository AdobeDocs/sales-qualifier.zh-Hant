# Sales Qualifier發行說明

**08-17-2026**

[!DNL Sales Qualifier]現在可作為獨立應用程式使用。 最初是作為Adobe Journey Optimizer B2B的一部分發行。

此版本包括：

* 透過AI產生的活動摘要和訊號型評分來排定潛在客戶和帳戶的優先順序
* 具有AI建議的步調和草擬電子郵件的目標導向參與計畫
* 電話、LinkedIn InMails和電子郵件評論的統一工作佇列
* 透過行事曆整合自動預約會議
* 將AI拓展納入您行動手冊資料的知識中心
* AI Chat，根據您的CRM、參與和知識中心資料提供自然語言問題
* 電子郵件和會議預約效能報表
* 在CRM或Outlook中存取的瀏覽器和電子郵件外掛程式
* 支援Salesforce和Microsoft Dynamics 365整合
